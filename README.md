# 📊 Power BI Sales Analysis Dashboard

## 🎯 Project Objective
Interactive sales dashboard created with Power BI to analyze retail sales performance across regions, products, and time periods. This dashboard helps stakeholders make data-driven decisions.

## 🛠️ Tools Used
- **Power BI Desktop** - Dashboard creation
- **Excel** - Data cleaning and preprocessing
- **DAX** - Calculated measures and KPIs

## 📂 Dataset
- **Source:** [Kaggle Sales Dataset](https://kaggle.com) 
- **Size:** 10,000+ rows
- **Columns:** Order Date, Region, Product, Category, Sales, Profit, Quantity

## 🔍 Key Insights
1. 📈 **North region** contributed highest sales (35% of total revenue)
2. 📅 **Q4** showed peak sales performance across all regions
3. 🏆 **Top 5 products** generated 60% of total revenue
4. 💰 **Electronics category** was the most profitable
5. 📉 **South region** needs improvement in profit margins

## 📊 Dashboard Features
- ✅ Region-wise sales filter (slicer)
- ✅ Time-based trend analysis (line chart)
- ✅ Top/Bottom performing products
- ✅ KPI Cards: Total Sales, Total Profit, Total Orders, Avg Order Value
- ✅ Category-wise distribution (donut chart)
- ✅ Monthly comparison (bar chart)
